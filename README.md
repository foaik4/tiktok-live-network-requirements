## 官方要求拆开看：50Mbps 是推荐值，不是及格线

TikTok 帮助页那条"上传 50Mbps 以上"经常被误读成硬性门槛。看原文语境就清楚了：它建议的是"通信稳定的 WiFi 环境"，50Mbps 是为了给波动留出充足余量，而不是低于这个数就开不了播。同一页面还明确写了 4G、5G 环境也可以直播，手机蜂窝网络的实际上行鲜有能到 50Mbps 的。

第三方实战口径则分成几档，彼此也有出入：

| 直播方式 | 最低上传 | 推荐上传 | 说明 |
| --- | --- | --- | --- |
| 手机直播 720p | 3–5Mbps | 5–10Mbps | 单人出镜、轻度带货 |
| OBS 推流 1080p/30fps | 10Mbps | 10–20Mbps | 电商带货、常规电脑直播 |
| OBS 推流 1080p/60fps | 15Mbps | 20Mbps 以上 | 高动态画面、才艺、游戏 |
| 多账号矩阵 | 按账号数叠加 | 每账号独立带宽 | 矩阵带货、无人直播 |

手机直播的底线，不同来源给出 3Mbps 和 5Mbps 两个版本，差 1–2Mbps。取保守值更稳妥：**手机按 5Mbps 起、电脑按 10Mbps 起规划**。推荐值普遍是最低值的 1.5–2 倍，原因是码率并非匀速消耗，高峰瞬间可能冲到平均值的 1.5–2 倍，带宽没有缓冲就会丢包。

## 延迟、丢包和流量：三个容易被忽略的数字

**延迟与丢包**。跨境直播圈常引用的阈值是 RTT 200ms 以内、理想 150ms 以内；丢包率官方容忍 2% 以下，实战想做到"不跳帧"最好压到 0.5% 以内。这套数字没有可查的官方原文，按经验值参考，但它解释了一个现象：带宽测速很漂亮，直播还是卡，问题往往出在抖动和丢包上，而不是峰值不够。

**流量消耗**。1080p 约 500MB/小时，720p 约 350MB/小时。一天播 4 小时、一个月播 25 天，1080p 大约消耗 50GB 上行流量；算上养号、回看、日常运营，一个月 100–200GB 比较稳妥，重度带货 500GB–1TB 不算夸张。选套餐时流量这一列比带宽更容易被低估。

**设备门槛**。官方故障排除文档写得很直接：满足最低系统要求时，只能使用摄像头以 **720p/30fps** 开播；达到推荐系统要求，才能覆盖多数 **1080p/60fps** 场景。同一份文档还提到，软件顶部"掉帧"数异常，**多数情况是网络问题**——预览画面看着正常，观众端却在卡。

## 带宽够了还是卡：问题多半不在宽带

这一段是整件事的转折点。

**家宽的上行是瓶颈。** 100M 下行能跑满，上行往往只有 10Mbps 甚至更少，而直播吃的是上传。测速网站上那个大数字是下行，跟推流没半点关系。

**后台程序在偷带宽。** 官方排查清单里列了一串：系统更新、下载软件、杀毒软件扫描、防火墙限制客户端连接服务器、代理、广告拦截、录屏、系统优化类工具。这些程序修改或监控网络活动时，会直接引发掉帧。还有一条常被忽略——网络硬件长时间运行会变慢，重启调制解调器和路由器经常能解决莫名其妙的卡顿。

**ISP 侧也会动手脚。** 部分运营商会缓存或压缩在线数据以节省带宽，官方建议换用其它 ISP 的网络测试；高峰时段共享网络的网速和稳定性会受影响，可以在非高峰时段开播。

**IP 层面才是决定流量的那一关。** 机房 IP、共享 IP、被反复使用过的 IP，容易触发限流甚至 0 播放。普通 VPN 的出口几乎都是机房 IP，且被大量用户共用，推流再顺也换不来观众；共享 VPS 的带宽被同机用户抢占，IP 同样落在机房段。从中国大陆网络直接推流还有一层硬伤：IP 归属地显示为中国大陆，算法不会把直播推给目标海外市场的用户。这也是"带宽解决能不能播，原生 IP 解决有没有流量"这句话的由来。

原生住宅 IP 指的是 IP 来自当地真实宽带运营商，与当地居民所用网络一致，风控检测时会被视为本地用户。丽萨主机的产品线就是围绕这一层做的——它在整件事里的角色是"换一个干净的落地环境"，而不是"给你更大的宽带"。

## FAQ

**50Mbps 是硬性要求吗？**
不是。官方原文是"建议"在 50Mbps 以上、通信稳定的 WiFi 环境下开播，属于留足余量的推荐值。实战中手机 5Mbps、电脑 10Mbps 就能跑起来，但要留出码率峰值的缓冲。

**手机 4G / 5G 能播吗？**
可以，官方明确注明 4G、5G 环境下也能直播。蜂窝网络的问题是不稳定和 IP 归属地，不是带宽数值本身。

**官方说 2Mbps 码率，为什么让我买 10M 宽带？**
2Mbps 是编码器的平均输出码率，网络侧要承受 1.5–2 倍的峰值，加上协议开销和重传，实际占用远高于 2Mbps。10Mbps 是给波动留的余量。

**用梯子或共享 VPS 行不行？**
技术上能推流，但出口 IP 多为机房段且被大量用户共用，容易触发限流、0 播放，账号风险高。长期运营建议用独享的原生住宅 IP 环境。

**一个 IP 能开几个 TikTok 号？**
养号阶段 3 个以内尚可，直播建议一账号一 IP。

**降画质凑合会不会影响账号？**
可以临时应急，但长期低画质直播会影响系统对账号的流量分配。带宽不够时，优先解决上行，而不是一路降分辨率。
